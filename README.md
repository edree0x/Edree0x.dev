# edree0x.dev

Personal portfolio website for **Ahmed Edrees** — Software Engineer specializing in full-stack web development, business systems, and technical consulting.

**Live:** [edree0x.dev](https://edree0x.dev)

## About

A modern, responsive portfolio built with vanilla HTML, CSS, and JavaScript. Features a dark/light theme toggle, smooth scroll animations, mobile-first design, and integrated booking via Cal.com.

## Features

- **Dark/Light Theme** — iOS-style toggle with localStorage persistence
- **Responsive Design** — Optimized for mobile, tablet, and desktop
- **Loading Animation** — SVG logo reveal with progress bar
- **Custom Cursor** — Interactive cursor with hover states
- **Scroll Animations** — Intersection Observer-powered fade-ins
- **Visitor Welcome Modal** — Geolocation-based personalized greeting
- **Cal.com Integration** — Inline booking calendar for scheduling meetings
- **Social Sidebars** — Fixed sidebars for quick access to social links

## Sections

| Section | Description |
|---------|-------------|
| Hero | Introduction and call-to-action |
| About | Background, skills, and profile image |
| Experience | Previous projects with tabbed navigation |
| Services | Web development, business systems, and consulting |
| Contact | Cal.com booking embed and contact links |

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, grid, flexbox, animations
- **JavaScript (ES6+)** — Vanilla JS, no frameworks
- **Font Awesome 6.5** — Icons
- **Google Fonts** — Inter + Roboto Mono
- **Cal.com** — Booking integration

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/edree0x/edree0x.dev.git
   ```

2. Open `index.html` in a browser — no build step required.

## Deployment

Hosted on **GitHub Pages** with a custom domain (`edree0x.dev`) configured via the `CNAME` file.
